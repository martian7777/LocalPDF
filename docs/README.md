# Android Engineering Docs Router

AI agents should read only task-relevant docs.

| Task | Read |
|---|---|
| Product/feature behavior | `product.md` |
| Architecture/modules/refactor | `architecture.md` |
| Compose/UI/UX/adaptive/accessibility | `ui-ux.md` |
| ViewModel/UDF/state | `presentation.md` |
| Domain rules/use cases | `domain.md` |
| Repository/data sources | `data.md` |
| Room/schema/migrations | `database.md` |
| API/network/errors | `networking.md` |
| Auth/security/permissions | `security.md` |
| Offline/sync/background work | `offline-sync.md` |
| Performance/battery/startup | `performance.md` |
| Tests/CI | `testing.md` |
| Crash/analytics/logs | `observability.md` |
| Build variants/config | `environments.md` |
| Release/Play Store/rollout | `release.md` |
| Support/incidents | `runbook.md` |
| New feature | `features/TEMPLATE.md` |
| Major decision | `adr/TEMPLATE.md` |

Do not load everything by default.
